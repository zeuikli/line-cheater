LINE Cheater

你的 LINE 清得乾乾淨淨

在瀏覽器中讀取 iOS LINE App Container 備份，搜尋聊天室、閱讀訊息並整理附件。

資料留在你的裝置 LINE 備份檔案可透過 iMazing 備份軟體取得；所有解析都在目前瀏覽器分頁內進行，關閉或重新整理頁面後資料不會被保留。連結預覽縮圖顯示時，瀏覽器可能向 LINE CDN 或縮圖來源讀取圖片。

載入方式
何時用「只讀訊息」？ 只想查閱訊息，或瀏覽器無法選取完整資料夾時使用。此模式沒有附件、縮圖與附件瘦身功能。
何時用「大型備份索引」？ Line.sqlite 接近或超過 1 GB，或要處理大型備份時，先用 CLI 產生並驗證索引，再回來載入。

支援 Safari、Firefox、Chrome 與 Edge 等可選取資料夾的瀏覽器。若 Firefox 版本無法選取資料夾，可改用「只讀訊息」選取 Messages/Line.sqlite，或用 CLI 產生大型索引。

備份檔案可透過 iMazing 備份軟體取得。只讀訊息模式不會載入附件；若備份另有同名 WAL／SHM 檔案，請改用完整備份模式以確保資料較完整。

大型索引只讀取分片資料；來源 SQLite 不會被瀏覽器重新載入。索引必須先由 CLI 驗證，若來源雜湊改變會標示為過期。

如何用 CLI 建立

請在專案資料夾的 Terminal 執行；--snapshot 指向包含 Container 與 Payload 的完整 LINE 備份資料夾。

python3 cli/line_migrator.py index \
  --snapshot "/path/to/line-backup" \
  --out "./line-reader-index" \
  --batch-size 5000

python3 cli/line_migrator.py verify-index \
  --index "./line-reader-index" \
  --source "/path/to/line-backup"

驗證通過後，回到這裡選取 line-reader-index 資料夾即可。完整參數與大型備份建議請查看 CLI.md。
